🤖 Telegram Order Bot

این ربات امکان نمایش محصولات و خدمات، ثبت سفارش مرحله‌به‌مرحله، پرداخت کارت‌به‌کارت و ارسال فیش پرداخت برای ادمین را فراهم می‌کند.

دیتابیس SQLite پروژه است و سفارش‌ها در آن ذخیره می‌شوند.

🚀 نصب و راه‌اندازی
1. دریافت پروژه

git clone YOUR_REPOSITORY_URL

سپس وارد پوشه پروژه شوید:


cd telegram_order_bot
2. ساخت محیط مجازی

پیشنهاد می‌شود پروژه را داخل Virtual Environment اجرا کنید.


python -m venv venv

فعال‌سازی در Windows:


venv\Scripts\activate
3. نصب وابستگی‌ها

pip install -r requirements.txt
4. تنظیم اطلاعات ربات

فایل:


config.py

را باز کنید.

مقادیر زیر را وارد کنید:


BOT_TOKEN = "YOUR_BOT_TOKEN"

ADMIN_ID = 123456789

CARD_NUMBER = "6037-0000-0000-0000"

CARD_OWNER = "نام صاحب کارت"
نکته

ADMIN_ID باید شناسه عددی اکانت تلگرام ادمین باشد.

5. اجرای ربات
python bot.py

اگر همه چیز درست باشد، در ترمینال مشاهده می‌کنید:

🤖 Bot is running...

حالا می‌توانید وارد ربات تلگرام شوید و دستور زیر را اجرا کنید:

/start

کاربر تصویر فیش را ارسال می‌کند و فیش برای ادمین ارسال می‌شود.
